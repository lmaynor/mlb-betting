### 2. mlb-build-all-features converted from service endpoint to Cloud Run Job

**Problem:** `/build-all-features` on the Cloud Run service blocked beezy.fyi API
traffic for ~22 minutes per day.

**Fix:** Created Cloud Run Job `mlb-build-all-features` that chains all 7 builders
sequentially via `/bin/sh -c "python3 -m runners.build_hr_features && python3 -m
runners.build_nrfi_features && ..."`. Job runs independently of the service so
beezy.fyi traffic is never blocked.

**Job config:**
- Image: `gcr.io/concrete-crow-445205-m4/mlb-betting:latest`
- Memory: 4Gi / 2CPU
- Task timeout: 3600s
- Command: `/bin/sh -c "python3 -m runners.build_hr_features && python3 -m runners.build_nrfi_features && python3 -m runners.build_k_features && python3 -m runners.build_f5_features && python3 -m runners.build_batter_hits_features && python3 -m runners.build_batter_tb_features && python3 -m runners.build_game_features"`
- SA: `mlb-betting-sa@concrete-crow-445205-m4.iam.gserviceaccount.com`
- Cloud SQL: `concrete-crow-445205-m4:us-central1:mlb-bets-db`

**IAM:** `roles/run.invoker` granted to `scheduler-invoker@...` on the job
(grants `run.jobs.run` permission).

**Scheduler update:** `mlb-build-all-features` scheduler job updated to trigger
the Cloud Run Job via OAuth/Run API:
- URI: `https://run.googleapis.com/v2/projects/concrete-crow-445205-m4/locations/us-central1/jobs/mlb-build-all-features:run`
- Auth: OAuth (`--oauth-service-account-email` + `--oauth-token-scope https://www.googleapis.com/auth/cloud-platform`)
- `--attempt-deadline 1800s` (Cloud Scheduler cap is 30 min; Run API returns async immediately)
- Body: `{}`

**Key gotcha discovered:** Cloud Scheduler `attempt-deadline` is capped at 1800s
(30 min). 3600s causes `INVALID_ARGUMENT: must be between 15s and 30m0s`. The
Run API call is async so the scheduler just needs time to receive the HTTP 200
acknowledgment (~1s); actual job execution runs independently under the job's
3600s task-timeout.
