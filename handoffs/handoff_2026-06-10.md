### 2. Font fix (Georgia-first, article body cleanup)

**Problem:** `.times` CSS class used `'Times New Roman'` as the primary font.
Times New Roman is a Windows system font -- unreliable on Vercel's Linux edge
runtime and absent on many non-Windows systems, causing fallback to browser
default serif (ugly). Root cause of intermittent page rendering failures.

**Fix:**
- `app/globals.css` `.times` class: `'Times New Roman', Times, serif` ->
  `Georgia, 'Times New Roman', Times, serif`. Georgia ships on every major OS
  and requires no web font load.
- `components/layout/footer.tsx` line 98: same fix applied to inline
  `fontFamily` style on footer nav links.
- Cleaned up duplicate `.article-body code` rule in `globals.css`: merged into
  one, removed stray `#10b981` color, changed `0.5px` pre border to `1px`,
  removed non-Dell `border-radius: 4px`.

Note: Inter and JetBrains Mono are loaded via `next/font/google` in
`app/layout.tsx`. No serif Google Font is loaded -- Georgia covers `.times`
via system fallback everywhere including Vercel edge.

### 3. Hero panel: red -> dark green

**Problem:** Hero left panel `background: '#c91525'` (bright red) was visually
alarming -- too loud for a page that should signal analytical confidence.

**Fix:** `components/landing/hero.tsx` background changed to `#0e1f0d`
(very dark forest green). White text and `rgba(255,255,255,0.7)` eyebrow copy
remain legible against this background. "Dell-red CTA panel" comment updated
to "dark-green CTA panel".

### 4. Nav centering + logo placeholder

**Problem:** Nav used `justify-content: space-between` with a minimal logo on
the left and multiple elements (X icon + auth + Discord sticker) on the right.
The right side was heavier, making the 7 nav links appear visually off-center
toward the left.

**Fix:** Switched inner container to `display: flex` (same as before) but:
- Logo link: added `flex: 1` so it takes equal space with the right section.
- Right section: added `flex: 1, justifyContent: 'flex-end'` to right-align
  the icons/auth while consuming equal horizontal space.
- Nav links (middle): remain at natural auto width, now visually centered.

Logo placeholder added: a `28x28px` div with `border: 1px dashed #444` and
a `?` label sits to the left of "BEEZY.FYI" text. Replace with
`<img src={logoSrc} alt="Beezy" />` when the final mark is ready.

Mobile behavior unchanged: `.nav-desktop` items have `display: none !important`
on mobile so they don't participate in flex layout; `.mobile-only` div remains
visible and naturally right-aligns due to the logo's `flex: 1`.

### 5. Pitcher headshot error handling (cheat sheet)

**Problem:** `cheat-sheet-client.tsx` rendered pitcher headshots from Savant
URLs (`headshotUrl`). If a URL 404s or fails to load, browsers show a broken-
image icon in the pick card's thumbnail column.

**Fix:** Added `onError={e => { (e.target as HTMLImageElement).style.display = 'none' }}`
to the `<img>` element. Silently hides the image on load failure; the system
label fallback (already rendered underneath via z-index) shows instead.
