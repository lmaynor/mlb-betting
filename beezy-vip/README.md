# Beezy.FYI

MLB picks and tools site powered by live XGBoost models.

## Stack

- **Frontend**: Next.js 14 (App Router), Tailwind CSS
- **Database**: Postgres (GCP Cloud SQL, read-only from website)
- **Auth**: Clerk
- **Payments**: Stripe
- **AI Content**: Anthropic API (article generation)
- **Deployment**: Vercel

---

## Setup

### 1. Install

```bash
npm install
```

### 2. Environment variables

Copy `.env.example` to `.env.local`:

```bash
cp .env.example .env.local
```

| Variable | Description |
|---|---|
| `DATABASE_URL` | GCP Cloud SQL connection string |
| `ANTHROPIC_API_KEY` | Article generation via Claude |
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` | Clerk public key |
| `CLERK_SECRET_KEY` | Clerk secret key |
| `STRIPE_SECRET_KEY` | Stripe secret (sk_live_...) |
| `STRIPE_WEBHOOK_SECRET` | From Stripe → Webhooks |
| `STRIPE_PRICE_STARTER` | Stripe Price ID for $29/mo |
| `STRIPE_PRICE_PRO` | Stripe Price ID for $79/mo |
| `STRIPE_PRICE_SEASON` | Stripe Price ID for $499 season |
| `ADMIN_SECRET_KEY` | Protects /api/admin/* |
| `CRON_SECRET` | Auto-generated by Vercel |
| `GCS_BUCKET_NAME` | GCS bucket for feature data |
| `NEXT_PUBLIC_BASE_URL` | https://beezy.fyi |
| `BETTING_API_URL` | https://api.beezy.fyi |
| `BETTING_API_KEY` | Matches `SITE_API_KEY` on Cloud Run |

### 3. Dev

```bash
npm run dev
```

## Article generation

Generate all 10 learn articles (hits Anthropic API, costs ~$0.50):

```bash
curl -X POST https://beezy.fyi/api/admin/learn/generate \
  -H "Content-Type: application/json" \
  -H "x-admin-key: YOUR_ADMIN_SECRET_KEY" \
  -d '{"all": true}'
```

Single article:

```bash
curl -X POST https://beezy.fyi/api/admin/learn/generate \
  -H "Content-Type: application/json" \
  -H "x-admin-key: YOUR_ADMIN_SECRET_KEY" \
  -d '{"slug": "what-is-nrfi"}'
```

Auto-refreshes every Sunday 03:00 UTC via `vercel.json` cron.

## Deployment

Push to `main` → Vercel auto-deploys. Set all env vars in Vercel dashboard first.

### Domain setup

Frontend:
- Add `beezy.fyi` and `www.beezy.fyi` to the Vercel project.
- In Porkbun DNS, point the apex `beezy.fyi` at Vercel and point `www` at Vercel.
- Set Vercel `NEXT_PUBLIC_BASE_URL=https://beezy.fyi`.

Backend:
- Map `api.beezy.fyi` to the Cloud Run service.
- In Porkbun DNS, add the records Cloud Run gives for `api.beezy.fyi`.
- Set Cloud Run `SITE_ORIGINS=https://beezy.fyi,https://www.beezy.fyi`.
- Set Vercel `BETTING_API_URL=https://api.beezy.fyi`.

## Database migrations

Run this once after first deploy to create required tables (`learn_articles`, add `league`/`book` columns):

```bash
curl -X POST https://beezy.fyi/api/db/migrate \
  -H "x-admin-key: YOUR_ADMIN_SECRET_KEY"
```

Check migration status:

```bash
curl https://beezy.fyi/api/db/migrate?key=YOUR_ADMIN_SECRET_KEY
```

```
1. Set all env vars in Vercel dashboard
2. Deploy: git push / vercel --prod
3. Run migrations: POST /api/db/migrate

5. Set Discord invite URL in nav.tsx + how-it-works.tsx
6. Flip PRE_LAUNCH = false in app/signup/page.tsx when ready
7. Flip PRE_LAUNCH = false in components/landing/pricing.tsx when ready
```
